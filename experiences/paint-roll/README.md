Roll fresh color across four filthy walls, manage paint coverage, and transform the whole room before the final reveal.

[Live demo](https://play.mint.gg/paint-roll) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/paint-roll)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/paint-roll dev
```
