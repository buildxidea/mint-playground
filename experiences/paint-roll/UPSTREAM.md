# Upstream provenance

Fresh Coat was imported from
[`CloudyLo001/paint-roll`](https://github.com/CloudyLo001/paint-roll)
at commit `7186264b4fec571671ba956b3956c9f9b37cdc43`.

The upstream repository does not declare a repository-wide software license.
On 2026-08-31, the upstream collaborator listed this project in the backlog for
`play.mint.gg`, and the developer explicitly approved importing it into Mint
Playground with the required publication approvals. That permission applies
only to this Playground adaptation; it does not assign licensing terms to the
upstream repository or authorize a separate public source mirror.

The adaptation preserves the upstream Vite and Three.js architecture, four-wall
painting loop, continuous GPU stamps, CPU coverage scoring, corner transitions,
paint colors, refilling, results reveal, confetti, HUD, and keyboard controls.
Mint-generated runtime PBR maps and the roller model load from verified
immutable Mint CDN artifacts recorded in `mint-assets.json`; the retired tray,
generated local copies, concept art, promotional site, repository metadata,
deployment tooling, and upstream documentation were excluded.
