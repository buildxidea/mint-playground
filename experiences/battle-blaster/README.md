# Battle Blaster

<a href="https://play.mint.gg/battle-blaster">

Explore five plasma casters, fit compatible modules, tune finishes and stats, compare configurations, and fire each weapon with its own sound.

[Live demo](https://play.mint.gg/battle-blaster) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/battle-blaster)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/battle-blaster dev
```
