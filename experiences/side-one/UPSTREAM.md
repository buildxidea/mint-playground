# Upstream provenance

Side One was imported from the Mint-owned private repository
[`mintdotgg/vinyl`](https://github.com/mintdotgg/vinyl) at commit
`36b3ee89c5441c33049b681b6f94999bf5d33a81`.

On 2026-07-30, the developer directed that this project be added to Play and
marked published. The Playground copy preserves the React App Router and
Three.js catalog while omitting the machine-local music helper from its public
runtime. It uses procedural sleeve artwork instead of redistributing the
source repository's catalog-display cover images.

Generated Mint turntable models and their previews load from verified Mint CDN
URLs and are not copied into this package.
