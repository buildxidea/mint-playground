# Upstream provenance

Dead Reckoning was imported from
[`B1toks/foggy-chess`](https://github.com/B1toks/foggy-chess) at commit
`69915676026e0d4f50e76d07475f19364ed3826c`.

The upstream repository did not declare a repository-wide software license.
On 2026-07-31, the developer directed that this project be added to Play and
marked published. This private Playground package preserves the upstream
Next.js Pages Router, React Three Fiber scene, chess rules, fog-of-war system,
and three-theme presentation without making a separate licensing claim about
the upstream source.

The upstream app's locally decimated Mint-generated models and Mist backdrop
were copied byte-for-byte to immutable, content-addressed Mint CDN keys for the
Playground runtime. The Ocean and Snow backdrops use their original verified
Mint CDN artifacts. Unused raw and experimental Gaussian-splat files, local
asset-processing tools, and development-only inspector routes were excluded.
