Deploy into a cinematic tactical FPS, fight through a six-room undead campus, or launch a survival arena from a shared map.

[Live demo](https://play.mint.gg/blacksite-echo) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/blacksite-echo)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/blacksite-echo dev
```
