# Upstream provenance

Solvane Vela was imported from
[`CloudyLo001/fake-car`](https://github.com/CloudyLo001/fake-car) at commit
`23c5e8be098288c8c8ea787c05a088794e515da2`.

The upstream repository did not declare a repository-wide software license.
On 2026-08-17, the developer explicitly approved all publication gates for
adding the project to Play with `status: "published"`, including publication
of the Mint Playground adaptation in `mintdotgg/mint-playground` under that
mirror's MIT license. This permission applies to the Playground adaptation
only and does not claim or change a license for the upstream repository.

The adaptation preserves the upstream Vite, TypeScript, and Three.js
architecture; six-generation scroll timeline; circular studio; period grades,
weather, typography, logos, specifications, and fictional advertising;
generation switcher; comparison and exploded views; and 2026 customizer.
Repository-only agent configuration, generation prompts, reference images,
model-processing and font-fetch scripts, npm and pnpm lockfiles, Git metadata,
build output, and local dependencies were excluded.

The six complete car bodies and sixteen era props used at runtime load from
verified immutable Mint CDN artifacts recorded in `mint-assets.json`. The 52
local generated runtime files (57,691,596 bytes), including source-derived web
decimations, were excluded; the showcase uses canonical or optimized Mint CDN
models instead. Authored local font files remain bundled through Vite.
