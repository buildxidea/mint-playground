# Upstream provenance

Project Forge-5 was imported from the private
[`mintdotgg/robots`](https://github.com/mintdotgg/robots) repository at commit
`81cf62ac2026292cc370b1cba8e677a357aee21a`.

The upstream repository did not declare a repository-wide software license.
On 2026-07-31, the developer directed that this project be added to Play and
marked published. This private Playground package preserves the upstream Vite
and Three.js architecture, five-robot roster, qualification missions, physics,
navigation, SparkJS Worlds, and outdoor freeplay without making a separate
licensing claim about the upstream source.

Mint-generated models, animation clips, props, colliders, and Worlds load from
their verified immutable Mint CDN artifacts and are recorded in
`mint-assets.json`. Generated binaries, generation evidence, test recordings,
asset-processing tools, and repository-only production acceptance material were
excluded from the portable capsule. Authored local font files remain bundled.
