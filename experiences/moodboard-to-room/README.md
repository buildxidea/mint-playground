# Moodboard to Room

<a href="https://play.mint.gg/moodboard-to-room">
  <img src="https://play.mint.gg/experience-assets/moodboard-to-room/social-card.webp" alt="A furnished sage-green bedroom with a platform bed, chair, plants, and woven rugs inside the room-design game." width="100%">
</a>

Interview eight opinionated guests, pack a limited furniture kit, arrange a 3D room, discover hidden quirks through live messages, and earn a judged guestbook result.

[Live demo](https://play.mint.gg/moodboard-to-room) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/moodboard-to-room)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/moodboard-to-room dev
```
