# Knightfall

Glide through a storm-lit city, thread aerial routes, catch a falling civilian, and land atop the signal tower.

[Live demo](https://play.mint.gg/knightfall) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/knightfall)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/knightfall dev
```
