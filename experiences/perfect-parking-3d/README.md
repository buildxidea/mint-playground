# Perfect Parking 3D

Drive three toy vehicles through a bright miniature parking lot, clear timed challenges, avoid obstacles, and earn precision scores.

[Live demo](https://play.mint.gg/perfect-parking-3d) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/perfect-parking-3d)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/perfect-parking-3d dev
```
