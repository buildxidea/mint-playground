Cut five increasingly demanding yards into clean target stripes before fuel runs out, then earn and improve persistent grades.

[Live demo](https://play.mint.gg/lawn-mowing-game) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/lawn-mowing-game)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/lawn-mowing-game dev
```
