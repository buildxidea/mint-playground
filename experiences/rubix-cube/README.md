# Rubix

<a href="https://play.mint.gg/rubix-cube">
  <img src="https://play.mint.gg/experience-assets/rubix-cube/social-card.webp" alt="A colorful tactile cube floating against a minimal dark studio interface labeled Rubix." width="100%">
</a>

Scramble, turn, resize, undo, and automatically solve a tactile multi-size cube with direct drag controls and crisp turn audio.

[Live demo](https://play.mint.gg/rubix-cube) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/rubix-cube)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/rubix-cube dev
```
