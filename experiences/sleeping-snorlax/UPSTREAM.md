# Upstream provenance

Sleeping Snorlax was imported from
[`cloudylo001/snorlaxsleeping`](https://github.com/cloudylo001/snorlaxsleeping)
at commit `8c61aaf9c15b2114afba47c7adddf55877702d7b`.

The upstream repository did not declare a repository-wide software license.
On 2026-08-03, the developer explicitly approved adding the project to Play
with all publication metadata and `status: "published"`, then approved
publishing the Mint Playground adaptation in `mintdotgg/mint-playground` under
that mirror's MIT license. This permission applies to the Playground adaptation
only and does not claim or change a license for the upstream repository. The
adaptation preserves the upstream Vite and Three.js architecture, procedural
deformation and reaction systems, combo loop, wake-up sequence, growth
settings, and audio presentation.

Mint-generated models and audio load from their verified immutable Mint CDN
artifacts and are recorded in `mint-assets.json`. The local generated copies,
GitHub deployment configuration, repository metadata, and development-only
files were excluded from the portable capsule.

Snorlax is a Pokemon character owned by Nintendo, Creatures Inc., and GAME
FREAK. The upstream project describes itself as personal and non-commercial.
