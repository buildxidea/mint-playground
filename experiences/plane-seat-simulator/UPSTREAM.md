# Upstream provenance

Plane Seat Simulator was imported from
[`CloudyLo001/planeseatsim`](https://github.com/CloudyLo001/planeseatsim) at
commit `bd6fd9e052a1b41a2e13a3f2f34a2f32cdc555ca`.

The upstream repository did not declare a repository-wide software license.
On 2026-08-17, the developer explicitly approved all publication gates for
adding the project to Play with `status: "published"`, including publication
of the Mint Playground adaptation in `mintdotgg/mint-playground` under that
mirror's MIT license. This permission applies to the Playground adaptation
only and does not claim or change a license for the upstream repository.

The adaptation preserves the upstream Vite, TypeScript, and Three.js
architecture; complete single-aisle cabin; clickable furnishings; camera
framing controls; interactive seat map; and day, sunset, and night lighting.
Repository-only agent configuration, deployment configuration, npm and pnpm
lockfiles, Git metadata, build output, and local dependencies were excluded.

The twelve models used by the cabin load from verified immutable Mint CDN
artifacts recorded in `mint-assets.json`. The 34 local generated model and
preview files (13,531,206 bytes) were excluded from the portable capsule.
