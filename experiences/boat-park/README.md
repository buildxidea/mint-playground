# Boat Park

Pilot nine wildly different boats through a working marina slalom, then master each vessel&#39;s momentum to dock safely.

[Live demo](https://play.mint.gg/boat-park) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/boat-park)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/boat-park dev
```
