# Upstream provenance

Boat Park was imported from
[`CloudyLo001/boat-repo`](https://github.com/CloudyLo001/boat-repo)
at commit `ef3d3de32f6b35c304994f60bb5fb264e04aa748`.

The upstream repository does not declare a repository-wide software license.
On 2026-08-31, the upstream collaborator listed this project in the backlog for
`play.mint.gg`, and the developer explicitly approved importing it into Mint
Playground with the required publication approvals. That permission applies
only to this Playground adaptation; it does not assign licensing terms to the
upstream repository or authorize a separate public source mirror.

The adaptation preserves the upstream Vite and Three.js architecture, nine-boat
progression, drift and buoyancy handling, marina slalom, docking, wildlife,
hazards, audio mix, HUD, and keyboard controls. Mint-generated runtime models
and audio load from verified immutable Mint CDN artifacts recorded in
`mint-assets.json`; generated local copies, source tests and probes, repository
metadata, deployment tooling, and upstream documentation were excluded.
