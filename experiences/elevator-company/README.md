Ride a cinematic luxury elevator through architectural stops, holding doors and meeting passengers as the tower&#39;s story unfolds.

[Live demo](https://play.mint.gg/elevator-company) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/elevator-company)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/elevator-company dev
```
