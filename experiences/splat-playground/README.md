# Splat Playground

<a href="https://play.mint.gg/splat-playground">
  <img src="https://play.mint.gg/experience-assets/splat-playground/social-card.webp" alt="A white android standing at a rain-soaked neon intersection inside a streamed Gaussian-splat city." width="100%">
</a>

Run, jump, and orbit four rigged characters across six streamed Gaussian-splat worlds with live world and character switching, collision, and adaptive lighting.

[Live demo](https://play.mint.gg/splat-playground) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/splat-playground)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/splat-playground dev
```
