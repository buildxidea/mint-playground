# Just Keep Swimming

Guide a clownfish through an endless jellyfish drift, threading bubble rings, bouncing off bells, and protecting a growing combo.

[Live demo](https://play.mint.gg/nemo) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/nemo)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/nemo dev
```
