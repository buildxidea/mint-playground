# Drone Delivery Dash

<a href="https://play.mint.gg/drone-delivery">
  <img src="https://play.mint.gg/experience-assets/drone-delivery/social-card.webp" alt="The Drone Delivery Dash title over a colorful miniature city of apartment rooftops and trees." width="100%">

Pilot a delivery quadrotor across eight rooftop routes, matching packages to pads while managing wind, hazards, landings, and battery.

[Live demo](https://play.mint.gg/drone-delivery) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/drone-delivery)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/drone-delivery dev
```
